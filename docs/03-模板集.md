# 模板集：能直接粘的文本

> 下面这些模板都是本项目的真版，抽干了业务内容。方括号是你要换的地方。
> 用法：建库时批量替换 `[项目名]`；单个文件的模板直接复制。

## 1. 计划卡模板

````markdown
# M[N] [一句话标题]

> 用户 [日期]：「[用户原话]」

## 目标
[做完之后什么状态叫完成，可验证]

## 范围（N 个动作）
1. **[动作名]**：[具体改哪个文件、改成什么]
2. **[动作名]**：…

## 本卡不做
- [容易被顺手带进去、但这次明确不做的]

## 文件
- 文件：[相对协作库根的文件路径]
- 文件：…

## 动作
[逐条，含改前改后关键内容]

## 验收

```verify
python ..\工具\kb\kb_check.py
python ..\工具\kb\read_state.py --doctor
```

## 偏差记录（如实记，不藏）
- [日期时间] [做了什么卡外的改动，为什么]

## 回滚
1. `cp /d/[备份目录]/[文件].bak-[时间戳] [文件]`
2. `python ..\工具\kb\kb_index.py`
3. `python ..\工具\kb\kb_check.py`
````

要点：**文件清单**和**验收命令块**是机器读的，别省；`verify` 会按清单核 sha256。

## 2. 接手语模板（给新会话，一条一条能直接跑）

````markdown
# 接手语（30 秒）

你是一个新会话，第一次进这个协作库。按顺序跑，每步都有"看到什么算正常"。

0.0 先判断我是什么档位
  python -c "import os,tempfile;p=os.path.join(tempfile.gettempdir(),'__t.txt');open(p,'w').write('x');print('TEMP 可写');os.remove(p)"
  然后试写工作区一次（write 工具建 `build/__wt.txt`，别用 shell 建）。
  - 能写工作区 = 全权档位：后文所有命令都能跑。
  - 只能写 TEMP = 受限档位：详见「受限会话能干什么」。
  注意：受限档位里用 write 工具建的文件**删不掉**（没有审批通道），别用 shell 建文件。

0.1 全库体检（几秒）
  python ..\工具\kb\kb_check.py
  - 13/13 PASS 或「结果：全部通过」= 正常，往下走。
  - 红了几项：先读 `00-规范\09-自检与验收方法.md` 的「假 FAIL 判读」，再决定要不要修。

0.2 收信
  python ..\工具\mailbox\mailbox.py digest --for [你的箱]
  - 看到信就按正文办；读自己的箱＝收信，会推进游标，正常。

0.3 认自己是谁
  python ..\工具\kb\read_state.py --me [你的会话 id 或角色名]
  - 报「（未登记）」＝正常（没被登记进名册的会话就这样），不是错。

0.4 读三份（只读，不改）
  README.md（路由表）→ 00-规范\04（硬规矩）→ 40-协作\_模板\接手交接.md

0.5 接活
  [改动前先写计划卡；卡外改动先问]

0.6 收尾
  ledger add → verify --card → kb_index → publish → status --json → kb_check → --doctor → 回收临时会话
````

## 3. 播报模板（跨格事实变更）

````markdown
【[维护线] 播报】[一句话：变了什么，几时生效]

1. 变了什么：[文件/规则/工具]
2. 影响谁：[哪些格子/哪些线的习惯要跟着改]
3. 要做什么：[照着改什么；不用改什么]
4. 证据：[自检输出/验收命令/计划卡文件名]
````

## 4. 否决账条目模板

````markdown
# [提案名]

- **现象**：[在哪次会话、哪一步、什么症状；有输出更好]
- **为什么否**：[根因；否掉的是"这个做法"还是"这个需求"]
- **现在走什么**：[替代方案，具体到命令/文件]
- **再提条件**：[什么事实变了就可以重新提；没有就写"暂不重提"]

## YYYY-MM-DD 复核：条件已满足 → 解禁
[只追加，不改上面的结论]
````

## 6. 子代理派活模板

````markdown
任务：只读审计，不改任何文件。
对象：[文件/目录]
判据：[什么算过期/冲突/不一致]
返回：一张表，列 `文件:行号 | 现在写的（原话） | 应该改成`；同一问题合并；最多 15 行；最后一行写"未修改任何文件"。
时间上限：[10 分钟]
禁止：修改文件、发信、重建索引。
````

## 7. 信箱信封约定

```
_消息/<箱>/<YYYYmmdd-HHMMSS>-from-<发件人>.md      # 未读
_消息/已处理/<箱>/<同文件名>                        # 已读归档
_消息/.cursors/<箱>                                 # 游标（纯文件名或 {"last": "..."}）
_消息/兜底待收/from-fallback-<时间>-<原名>.md       # 受限会话发信的落点
```

## 8. 收尾清单（复制到每张卡）

```
- [ ] 计划卡写好（含文件清单 + verify 块）
- [ ] ledger add：每个文件一行
- [ ] verify --card "40-协作\_计划卡\<卡名>.md" → 全 PASS
- [ ] kb_index.py（索引落后就红）
- [ ] publish --scope all --from <自己的箱>（改了共用格必须发）
- [ ] status --json（快照跟上）
- [ ] kb_check.py → 13/13
- [ ] read_state.py --doctor → PASS
- [ ] 子代理/临时会话已回收
```
