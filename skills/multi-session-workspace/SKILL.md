# 多会话协作库

版本：2026-10-23（v2：示例脱敏、边界独立、播报收窄）

## 什么时候用

- 用户同时开多条会话（日常 / 邮件 / 某课程 / 资料维护），资料要共用但不能互相踩。
- 出现"两份文档说法不一样""改完没人知道""新会话开工要人肉交代半小时"。
- 用户说：几个会话分工、共用资料、别互相覆盖、新会话接手。

## 什么时候别用

- 只有一条会话、资料几十个文件：一个 README + 一个索引脚本就够，别加信箱。
- 用户只是想"整理一下某个目录"：那是索引/归档的活，不是协作库。
- 团队里没人愿意维护规则：先只做台账与一条自检，别铺全景。

## 四条不变量

1. **一箱一线**：每个会话一个信箱箱，绝不共用。共用箱 = 谁先读谁推进游标，另一条线**永久丢信且不报错**。
2. **一格一主**：目录一个主人，主人之外只读；共用格（规范/模板/工具/索引）由一条维护线单点写。
3. **事实单落点**：同一事实只有一个权威文件；索引、名册、快照都是生成物，不手改。
4. **写库单点**：多会话并行读；写共用格、记账、播报、重建索引由一条线做（权限全开也不改这条）。

## 骨架

```
<workspace>/kb/
  00-规范/          # 规矩：环境/工具/坑位/偏好/目录/文档/权限/编辑/自检
  <角色>/           # 一格一主，如 10-主对话、20-学习、30-邮件
  40-协作/
    _计划卡/        # 每批活一张卡 + ledger.tsv（台账与验收见 card-ledger-workflow）
    _消息/<箱>/     # 未读；.cursors/<箱> 游标；已处理/<箱>/ 归档
    _播报/          # 跨格变更广播
    _模板/          # 启动语、接手语；接手流程见 session-handoff
  交办/             # 跨权限请求
  _索引.md          # 生成物
  修订记录.md       # 每轮一行
```

## 信箱协议

- 信封：`<YYYYmmdd-HHMMSS>-from-<发件人ascii>.md`。**文件名不用中文**（排序、游标比较、跨平台复制都会出怪问题）。
- 兜底：受限档位发不出时落 `%TEMP%\dsh-mailbox\outbox\`，`send` 打印完整路径；`digest` 时自动 sweep 收到。
- 游标：每箱一个文件，内容为最后归档的文件名；**同时兼容** `{"last": "..."}`（别的会话可能写成 JSON）。
- 读自己的箱 = 收信（归档 + 推进游标）；探别人的箱必须 `--peek`。
- 正文：四行头（发件人 / 收件人 / 时间 / `给：<会话名>`）；出错带机器码 `error_code: EPERM_WRITE` 之类。

## 名册

- AUTO 段由脚本从运行时扫（会话 id / 状态 / 有无目录），只重写标记之间的表。
- 手工段写角色、id、格子、说明。
- 校验器只查三件：手工段引用的 id 在 AUTO 段里；AUTO 无重复；守护/桥会话有目录且属本工作区。
- "归档"只算提示不算故障（归档 = 侧栏隐藏，看心跳/日志证通道还活着）。

## 播报（四段，缺一段等于没发）

变了什么 / 影响谁 / 要做什么 / 证据在哪。跨格事实变更（规范、模板、工具、索引）**当轮必发**，自检里要有这一项。

## 例子（脱敏真例）

播报文件名：`40-协作\_播报\20261023-203210-补充：协作库方法包编号_08→12，5_个_skill_已装进本机.md`

名册手工段：

```
| 角色 | 会话 id | 格子 | 说明 |
| --- | --- | --- | --- |
| 维护线 | `session-<id>-…` | 协作库全部 | 结构/规范/索引/自检/台账 |
```

## 验收

- 发一封到 A 箱：A 线 `digest` 看到、B 线看不到；A 再 `digest` 为空 → 隔离与游标都正常。
- 名册校验返回 PASS；未登记的会话能靠 `read_state --me` 认出自己（属正常）。
- 新会话按 `session-handoff` 的清单跑完，报告"卡住=无"。

## 常见坑

- 两个会话共用一个箱 → 丢信不报错（本库真实事故）。
- 信封名带中文 → 游标比较错乱、某箱永远显示 0 未读。
- 改了共用格忘了播报 → 自检"共用格已播报"必红。
- 手工名册被生成器整表覆盖 → 拆 AUTO 段与手工段。
